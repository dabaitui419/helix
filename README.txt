【页面功能（13 个页签）】
  ①  收益测算（左螺旋）   每日收益 = 当日算力 × 0.28%，算力每天 ×0.9972；支持复投
  ②  右螺旋收益          按钱包地址查询：个人/网络算力、三池奖励、今日右螺旋收益
                         底部附 P 级成员名单（307 人，可搜索、点地址查官方动态、一键复制）
  ③  全网排放全景        配额 → 执行预算 → 实际排放，57 天完整曲线
  ④  P 等级测算          三区业绩 + 锁仓 + 下线三把锁，逐级对照
  ⑤  回本测算            0.7%/0.28% 模型回本天数 + 复投 30/60/90/180/270/360 天对比
  ⑥  参数与来源          链上实测参数、白皮书 vs 链上对照、公式汇总
  ⑦  合约查询            内置 189 条合约库，点击自动查链上信息
  ⑧  钱包资产            双链原生币 + 已知代币 + NFT + AiLGNS 五池 LP 份额
  ⑨  资金监控            底池/金库余额巡检
  ⑩  AiLGNS 观测台       今日结算、算力参与、P 级分布、流动性池数据
  ⑪  小工具              单位换算、十六进制转换、21 个常用网站
  ⑫  三个池是什么        增长池 / 网络池 / 共识池的规则、实际发放与查询方式
  ⑬  卖出冲击            AiLGNS 卖多少 → 币价变成多少（链上真实储备 + 多池分流）

【如何更新网站】
  1. 本机改好 index.html（或拿到新版文件）
  2. 打开 https://github.com/dabaitui419/helix/upload/main
  3. 把新的 index.html 拖进虚线框（同名会覆盖）
  4. 拉到底点「提交更改 / Commit changes」
  5. 等 30 秒~1 分钟，GitHub Pages 自动重新部署
  6. 打开网站按 Ctrl+F5 强制刷新（手机需清缓存）
